🎯 Problem Statement & Setup

Predict fish weight (g) non-invasively from underwater video using morphometric measurements

📷 Data Capture

  • 15 individual fish recorded in a controlled tank
  • Top view camera → Length, Width, Area, Perimeter
  • Front view camera → Height
  • Calibration tapes for pixel-to-cm conversion
  • Weight range: 9.6 – 81.9 g

🔬 Pipeline Goal

  • Extract fish silhouette (mask) from each frame
  • Compute morphometric features (L, W, H, A, P)
  • Train regression models for weight prediction
  • Achieve publication-ready, peer-reviewable accuracy
  • No data leakage or contaminated features

📸 Camera Setup & The Challenge

✅ Top View

Relatively clear. Good for many frames. Fish silhouette often extractable via background subtraction.

❌ Front View

Severely murky & turbid water. Fish nearly invisible. Masking fails for most frames.

❌ Front View 2

Another front view sample showing extreme low visibility — the core challenge of this project.

🔧 Method 1: Classic CV Pipeline

Background subtraction + motion segmentation with enhancement techniques

Pipeline Steps

  • Median background modeling (120 sampled frames)
  • Gaussian blur → absolute difference → threshold
  • HSV-based tape exclusion masks
  • Morphological cleaning (Open → Close → Erode/Dilate)
  • Convex hull geometry for measurements
  • Quality filtering (blur score, border margin, aspect ratio)

Enhancement Techniques Applied

  • Auto Gamma Correction — exposure normalization
  • CLAHE — local contrast (LAB color space)
  • Multi-Scale Retinex — turbidity/haze removal
  • Non-Local Means Denoising — noise reduction
  • Bilateral Filter — edge-preserving smoothing
  • Unsharp Mask — edge sharpening in haze

📊 Classic CV: Mixed Results

✅ Top View — Worked Well

  • Good mask extraction for many frames
  • Background subtraction effective from above
  • Clean silhouettes → accurate Length, Width, Area
  • Enhancement (CLAHE + Gamma) improved consistency
  • Up to 200 quality frames per fish extracted

❌ Front View — Major Failures

  • Murky, turbid water made fish nearly invisible
  • Masking failed for most frames
  • Only a few frames produced usable masks
  • Height (H) measurements were unreliable
  • Even Retinex + Unsharp couldn't rescue visibility
  • This led to need for manual annotation

Key Insight Classic CV enhancement alone was NOT sufficient for the front view due to extreme water turbidity

✍️ The Turning Point: Manual Annotation

Neither Classic CV nor SAM could reliably segment the front view → manual annotation required

Why Manual Annotation?

  • Front-view masks were too noisy for accurate Height
  • Automated methods worked on few frames only
  • Publication-quality data demands reliable measurements
  • Ground truth needed for training a detection model
  • MOT 1.1 format bounding box annotations created

Annotation Scope

  • 15 fish × 2 views (top + front)
  • Annotations for both top-view and front-view videos
  • Bounding boxes in MOT ground truth format
  • Frames organized by range directories
  • This became the foundation for the YOLO approach

🚀 Method 3: YOLO Object Detection

Leveraging manual annotations to train a robust fish detector

Training Pipeline

  • MOT 1.1 annotations → converted to YOLO format
  • 85/15 train/val split (frame-level, shuffled)
  • Trained YOLOv8m, YOLO11m, YOLO12m
  • Also trained YOLO11m-seg (segmentation)
  • 150 epochs, imgsz=640, AdamW optimizer

Data Augmentation

  • HSV augmentation (h=0.015, s=0.7, v=0.4)
  • Rotation (±10°), Translation (10%), Scale (50%)
  • Horizontal & Vertical flips (50% each)
  • Mosaic (100%), MixUp (10%)
  • Cosine LR schedule, warmup=5 epochs

Key Advantage YOLO provides reliable bounding boxes in BOTH views, enabling SAM-prompted segmentation within detected regions

🔗 Feature Correlation Analysis

Key Observations

  • Width ↔ Weight: 0.52 — strongest single predictor
  • Area ↔ Weight: 0.26 — moderate correlation
  • Length ↔ Weight: -0.26 — surprisingly negative
  • Height ↔ Weight: -0.14 — weak, due to noisy front-view masks
  • Area ↔ Width: 0.89 — high collinearity
  • Perimeter ↔ Length: 0.86 — high collinearity

Implication

The weak Height correlation directly reflects the front-view masking challenges — motivating the YOLO + SAM approach for better segmentation.
